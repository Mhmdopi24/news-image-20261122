One day on Earth: Sunday 22 November 2026 in a single code-drawn picture — 30 stories, a UTC timeline, three illustrated leads and a date check. The program paints the whole 1024x1024 image itself with a small pixel font, so every word stays crisp, and pastes in three flat vector illustrations made for this entry. Every story was first reported on Sunday 22 November 2026; stories from earlier days are named only in the date-check box as deliberately left out.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `out/entry.png` (1024x1024 PNG, under 1 MiB). The program runs twice with byte-identical output and needs no network.
